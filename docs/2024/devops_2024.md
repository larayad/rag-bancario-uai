# Subgerencia DevOps - 2024

## Principales Logros

### I+DevOps

- Pruebas automáticas con GAT y GAT+.
- Masificación de nuevas prácticas.
- Implementación de GitHub y habilitación de Copilot.
- DevOps en Bci Miami.

### CI/CD

- Pipelines 100% automáticos para XOps y TD.
- Habilitación de pipelines en GitHub Actions.
- Categorización automática de bloqueos.

### DevSecOps

- Tolerancia cero en vulnerabilidades de librerías de terceros.
- Shift Left de seguridad y calidad de microservicios.

### Nuevo Modelo Operativo

- 12 procesos nuevos.
- 4 procesos masificados a 90 equipos en TD.
- Procesos basados en calidad y seguridad.

## Visión 2025

- DevOps como plataforma.
- Impulsar modelo operativo.
- Lograr mayor autonomía para equipos de desarrollo.
- Evolución de roles.
- Innovación e investigación de tecnologías emergentes.
- Mejora continua de procesos y automatizaciones.
