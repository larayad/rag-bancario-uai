# Contexto Organizacional TI Digital - 2024

Toda esta información corresponde al año 2024.

## Contexto

Durante 2024 la organización se identifica como **Gerencia de TI Digital**.

A partir de 2026 esta gerencia pasa a denominarse **Gerencia Desarrollo e Integración de Soluciones**.

Este documento debe usarse como contexto temporal para responder preguntas sobre la estructura previa a 2026.
