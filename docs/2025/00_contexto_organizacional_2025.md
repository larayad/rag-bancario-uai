# Contexto Organizacional TI Digital - 2025

Toda esta información corresponde al año 2025.

## Contexto

Durante 2025 la organización se identifica como **Gerencia de TI Digital**.

A partir de 2026 esta gerencia pasa a denominarse **Gerencia Desarrollo e Integración de Soluciones**.

## Uso recomendado para RAG

Este documento debe usarse para comparar la evolución entre 2024, 2025 y la nueva estructura 2026.
