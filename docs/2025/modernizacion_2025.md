# Subgerencia de Modernización - 2025

## Visión y Propósito

Somos el equipo que acelera la transformación digital del banco, habilitando capacidades digitales y mitigando riesgos de obsolescencia tecnológica.

La misión es transformar sistemas y procesos críticos del banco mediante automatización.

## Logros 2025

- Modernización de 859 funcionalidades OSB a 122 microservicios y 61 integraciones.
- Proceso de desarrollo industrializado para transformar portales web de forma acelerada.
- Avance industrializado:
  - MFE: 44%.
  - Microservicios de orquestación: 47%.
  - Microservicios de negocio: 70%.
- Modernización de 70 funcionalidades de Portal Web Personas y Pyme en:
  - 96 MFE.
  - 224 microservicios.
  - 17 integraciones.
- Habilitación de proceso de desarrollo de software automático.

## Próximos Pasos

- Liberación a clientes de funcionalidades restantes de OSB.
- Certificación y paso a producción de portales modernizados Personas y Pyme.
- Pilotos y masificación del proceso de desarrollo de software automático.
