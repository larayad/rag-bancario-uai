# Agente RAG Bancario

Prototipo de agente RAG para consultar documentación interna de subgerencias del banco.

## Objetivo
Identificar hitos, próximos pasos, responsables y cambios organizacionales a partir de documentos internos.

## Alcance
- Documentos de negocio
- Embeddings y Vector DB
- Agente orquestador
- Workers básicos
- Fiscalizador básico
- Evaluación con consultas reales
- Registro básico de interacciones

## Fuera del alcance inicial
- Cloud Run
- Go Live productivo
- Integración con sistemas core
